# devlog 2026-08-25 — KB-0.3：MCP 写入工具（agent 终于能往知识库里加东西）

> 上游：[22-mcp spec](../specs/22-mcp.md)、[迭代计划 KB-0.3](../plans/2026-08-24-知识库引擎迭代计划.md)。
> 前置：KB-0.2 远端模式（同日落地）——**写入工具依赖它**，理由见下。

## 做什么 / 为什么

MCP 面此前**全只读**（`search` + `resolve_citation`）。定位是"让 AI agent 很方便地使用的知识库"，
那"agent 读到有用的东西 → 存进去 → 以后能搜到"是基本闭环，而这个闭环缺一半。
本次加 `index_chunks`（薄封装 `/v1/index`，doc 级替换）。

`ingest_document`（收原始文件）**不做**：它依赖 KB-3 的上传端点，且解析归调用方这条边界
未被 2026-08-24 的 ADR 修订推翻（修订只收回"摄取作业面"的**状态**，不是解析算力）。

## 两个判断

### 1. 写入工具**只在远端档出现**——不是"出现了但会报错"

C1 的全表版。本地档的身份是进程级常量、不是每请求身份，在它上面开写入口 = 让引擎
"替调用方猜写入 ACL"，正是 server 用 403 拒绝掉的那件事。所以：
- 本地档的 `tools/list` 里**没有**这个工具；
- 并且它在本地档**真的不可调用**（否则"没宣称但能调"就是又一个暗门）——
  调用返回可自纠的错误并指路远端档。

这条也顺带**兑现了 KB-0.2 留下的裁定条件**：22-mcp spec 把"本地档保留还是弃用"的裁定权交给
KB-0.2 实施者，条件是本地档保持 ①fail-closed ②**只读** ③如实只宣称 keyword。
本次把 ② 落实为代码 + 测试，三条齐备 ⇒ 已回写 spec，裁定为**保留**。

### 2. chunk 里夹带 `tenant`/`acl` → **显式拒绝**，而不是让 server 静默覆盖

server 的 `apply_ingest_identity` 无条件用调用者身份覆盖 chunk 的 tenant/acl，
所以夹带本来"无害"。但**静默覆盖会让 agent 以为自己控制了可见性**——这正是本仓反复在修的
那类"悄悄替调用方决定"（fail-closed 的空 tags→public、MCP 的 hybrid→keyword、
CDC 的旁表 DELETE→误删）。宁可让它读到一句话："写入身份由服务端从 API key 注入，
要写到别的租户下请换一把 key。"

## 活服务验证 —— **第三次**抓到单测漏掉的问题

起真 server 实跑，`index_chunks` 直接 **422**：

```
server 返回 422: ... chunks[0]: missing field `doc_id`
```

`core::Chunk.doc_id` 是必填，而 `/v1/index` 的 `IndexChunk` 用 `#[serde(flatten)]` 展开它
⇒ 缺了在**反序列化阶段**就 422，而 `apply_ingest_identity` 的覆盖发生在那之后、救不了。
修法：MCP 替 agent 把顶层 `doc_id` 补进每条 chunk（值反正会被 server 覆盖成同一个）——
让 agent 在每条 chunk 里重复一遍 doc_id 是纯粹的仪式。

修完再跑，闭环成立：

```
agent 写入 : {"indexed":1}
立即搜到   : {"hits":[{"citation_id":"kb:agent-note:0", …}]}
```

> **这是本仓连续第三次由"活服务验证"抓到单测漏掉的错**（① fail-closed 的 metrics 畸形输出、
> ② KB-0.2 探测的字段名写错、③ 本次的必填字段）。三次的根因**完全一致**：
> **单测的输入/桩是我自己造的，造错了就自洽地绿**。②③ 尤其像——mock server 无脑返回固定 JSON、
> 从不校验请求体，于是"发出去的 body 少一个必填字段"这类错它天然抓不到。
>
> **已采取的对策**（写进本次测试）：凡与外部实际接口对接的地方，
> ① mock 响应照抄真实响应的字段名；② **断言出站请求体**，而不只是断言"没报错"。
> 本次给 `remote_index_chunks_posts_to_v1_index` 补了 `body["chunks"][0]["doc_id"]` 的断言——
> 这条断言若早写十分钟，422 就不会跑到活服务那一步才暴露。
