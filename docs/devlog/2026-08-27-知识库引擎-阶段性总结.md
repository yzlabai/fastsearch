## 2. 关键判断（按影响排序）

### 2.1 纠正了提问的前提

问题问的是"没有文档处理和文档解析"。读完代码后结论是**一半不成立**：
docparse 早已 subtree 进 `vendor/`，10 种解析器 + PP-OCR + UniRec 表格都在，分块器也有。

**真缺口是提问没点破的那半**：解析和分块**都只在 CLI 客户端进程内**，server 只认切好的 chunk
——没有上传入口、没有作业、没有状态、没有文档列表。

⇒ 如果直接照提问去"加解析能力"，会做错方向。**先纠前提，再动手**。

### 2.2 定位一变，优先级全变

中途明确了定位：**让 AI agent 很方便地使用的知识库**——使用者是 agent，不是知识库管理员。

这条重排了整个计划：原计划把重心压在检索质量天花板（KB-2），但"方不方便用"由 **agent 面**决定，
而那张脸（MCP）恰恰是四张脸里最弱、**且会对 agent 说谎**的一张。于是新增最高优先级的 KB-0 阶段，
并按此顺序做完：诚实化 → 远端档 → 写入闭环 → 上下文预算 → 自描述。

### 2.3 ADR 走了一次正式的部分推翻

原 ADR《职责边界》把"摄取任务队列"划给调用方。为了让"文档直接给 fastsearch"成立，
**按 ADR 自己要求的方式**产出了[修订记录](../governance/2026-08-24-职责边界修订-摄取作业面收回引擎.md)：
只推翻一项、逐条回应原 ADR 的三条理由、以**七条红线**钉住边界。

其中第 ② 条理由（"会削弱 ACL 不可绕过"）不是被反驳，而是被**当作对价押上**——
承诺作业面继续对身份没有观点。副作用是 **KB-4 的封禁反而更强了**：启动它就要连带回滚 KB-3。

## 5. 三条反复出现的规律（本轮最值得留下的东西）

### 5.1 "宣称的能力 ≠ 实际能力"是这个仓库的系统性缺陷类型

同一形状出现了至少五次：MCP 宣称 hybrid、`vector` 是暗门、`req.explain` 只有声明零使用、
`caps()` 照抄配置、两个 SDK 客户端侧的 `acl` 默认值（服务端总是覆盖，等于教给调用方一个假象）。

**共性**：都不会报错，都在"看起来能用"的表象下给出错误的东西。
⇒ 本轮把"宣称 = 实测"立成硬契约（22-mcp spec 的 C1），并做成**双向**：
**能兑现却不宣称的，也是违例**。

### 5.2 "把碰巧的安全变成显式的"

多处正确性此前依赖"目前恰好如此"：`SET TABLE` 碰巧让 publication 单表因而挡住了旁表误删、
`vector` 碰巧能用但没人知道、维度校验碰巧在下层已经做了。

本轮的对策不是加注释，是**做成结构性保证**：`relation_is_chunks` 形状守卫、
`SignalType` 穷尽 `match`（新增类型不回答规则就编不过）、
唯一索引 `(tenant, collection, doc_id)`（想加版本必须先删索引，评审必然看见）。

### 5.3 "我以为做了"和"真的做了"之间必须有校验

本轮被抓到四次，**每次根因都一样**：

| 次 | 表现 | 抓到它的 |
|---|---|---|
| 1 | metrics 缩进破坏 Prometheus 格式 | 实跑二进制 |
| 2 | 探测读 `server.backend`、实际字段是 `vector_backend` | 实跑二进制 |
| 3 | `index_chunks` 少 `doc_id` 必填字段 → 422 | 实跑二进制 |
| 4 | commit message 描述了**没发生的**计划回写 | `git show --stat` |

前三次的根因是同一句话：**单测的桩是我自己造的，造错了就自洽地绿**。
mock 无脑返回固定 JSON、从不校验请求体，于是"发出去的 body 少一个必填字段"这类错天然抓不到。

**对策已落到代码里**：mock 响应照抄真实响应的字段名；**断言出站请求体**而不只是断言"没报错"。
效果可验证——KB-2.4 里同一类 Prometheus 缩进错**在单测阶段就红了**（因为写了"遍历所有行断言顶格"），
KB-0.4 之后**没有再被活服务抓到新问题**。

## 6. 关于并行

Wave 1 开了 4 个零文件重叠的并行作业（3 份 spec + 1 个实施），**产出最值钱的不是文档，是三条 bug**。
Wave 2 **没有再开并行**——不是忘了，是 C1 通道内部本就串行，其余通道要么缺前置要么是单人小改。

⇒ 记下的结论：**并行的收益随"可同时推进的独立通道数"下降而消失**（Wave 1 有 4 条，Wave 2 只有 1 条）。
为并行而并行没有意义。

## 7. 现状一句话

**Agent 面已闭合**：agent 能诚实地知道这个实例能干什么、能搜、能溯源、能写入、能控制上下文预算。
**摄取面补上了地基与契约**：图片字节进得来了，非 Rust 调用方有正式指南和适配 helper。
**检索质量面只动了内核**：N 路融合能力有了，但**引擎仍只喂两路**——这一条在三处都做了记账，
不得读成"多路召回已上线"。

剩下的路，要么等一个决策，要么等一个 PG，要么等一个模型服务。
