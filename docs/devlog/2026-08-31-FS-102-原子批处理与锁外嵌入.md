# FS-102：原子批处理与锁外嵌入

> 日期：2026-08-31
> 状态：完成
> 对应计划：[FS-102](../plans/2026-08-30-迭代开发计划.md#fs-102-indexsink-原子性与批量嵌入--2026-08-31)

## 1. 本轮结果

FS-102 将 CDC 从“每个 chunk 先改 text、再逐次访问外部服务”改为整批 prepare→publish：

- 全批先做 metadata/媒资解析和一次 `embed_multi`，检查返回数量、维度与有限值。
- pgvector set/clear 在一个 PostgreSQL 事务中写穿，任一项失败整批 rollback。
- 准备成功后才排队 text/vector 变更；发布前模拟整批向量维度边界，Tantivy 本地失败会 rollback 未提交 writer。
- `Applier` 只在 apply 与 commit 都成功后推进本批水位。
- server 的 peek、对象读取和嵌入移到全局 Engine 锁外；PG 写穿事务与本地发布/持久化持锁，阻断运行中的跨索引半版本读取。
- bootstrap 与 rebuild 复用同一批处理，不再逐 chunk 请求嵌入服务。

## 2. 失败策略

本轮选择“整批准备、整批发布、失败重放”：

```text
peek（slot 不推进）
  -> prepare：锁外校验 + 一次 embed_multi
  -> publish：锁内 PG 写穿事务 + 更新 text/vector + persist checkpoint
  -> advance slot
```

prepare 任一步失败时本地派生状态不变；PG 写穿自身为单事务，且提交到本地发布完成期间搜索被 Engine 锁阻断。纯本地模式 apply 后、persist 前进程退出时，未提交 text 与内存 vector 随进程丢弃，slot 未推进；重启从上一检查点重放。成功路径仍以 GlobalId upsert/delete 的幂等性收敛。

PostgreSQL 事务与本地 Tantivy/vector/checkpoint 文件之间没有可用的分布式 2PC；进程恰在两者提交之间退出时，只能依赖 slot 重放最终收敛。Turbo rerank sidecar I/O、Tantivy commit 等本地存储错误也不能只靠维度预检回滚。两类窗口都需要 staging/swap 或持久化批次意图、启动恢复和 readiness 阻断，明确纳入 FS-103。本轮“原子”只指已测试的准备期、确定性向量约束与 PG 批内失败，不掩盖物理存储边界。

FS-103 继续统一 commit LSN、slot 并发首建和 peek/apply/persist/advance 四阶段健康状态；本轮没有把 polling 改为流式复制，也没有扩大为 RwLock/索引分片。

## 3. TDD 故障注入

- commit 失败：RED 时 `Applier` 错误推进到 LSN 8；修复后保持批前 LSN 0。
- embedding timeout：RED 时第一条 text 留在 writer，可被后续 commit 顺带发布；修复后 keyword/vector 均为空，换健康 embedder 重试后共同出现。
- 第二条返回维度错误：负控留下第一条 vector 而 text 已 rollback；全批返回值预检后两路均停在旧版本，重试收敛。
- 发布期索引维度冲突：负控先 Delete 旧向量、后在 Upsert 才失败；模拟整批维度边界后在任何本地改动前拒绝，旧 keyword/vector 均保留。
- 后端维度上限：旋转档 `Clear` 后接 8193 维 Upsert 的负控会先清空旧向量；统一后端约束预检后在 Clear 前拒绝并保留旧版本。
- 待 PG 写穿的公开 prepared batch 不能直接发布；调用方必须走封装了锁内 write-through 的共享消费路径。
- 提交后复审发现 `Applier::apply` 与 `IndexSink::apply_changes` 各自维护一套 `Change` 递归分派；batch-only sink 负控证明单条路径绕过批次接缝，修复后单条/批量共用唯一分派入口。
- PG 第二条写穿失败：真实触发器负控留下第一条 embedding；事务化后 vector/keyword 均无新版本，移除触发器后同批两条共同命中。
- 锁外嵌入：负控在 200ms embedding 期间无法于 75ms 内取得 Engine 锁；改造后可取得且准备结果尚不可见，完成后一次发布。
- 进程退出：apply 后刻意不 persist、不 advance 并 drop Engine；重启磁盘两路均为空，slot 重放后共同命中。
